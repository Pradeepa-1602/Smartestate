# SmartEstate – Real Estate Web Application

SmartEstate is a full-stack web application for listing, browsing, and managing real estate properties.

## Features

* User-friendly property listing
* Buyer and seller modules
* Seller dashboard
* Property management
* Wishlist and enquiry features
* REST API integration
* MySQL database

## Technologies

* HTML, CSS, JavaScript, Bootstrap
* Node.js, Express.js
* MySQL
* AWS, Docker, Jenkins

## Project Objective

To develop a simple and efficient platform for managing real estate properties while gaining practical experience in full-stack development and cloud deployment.
